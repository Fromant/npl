# Задача 1.1. Сумма квадратов на потоках

## Назначение

Программа считает сумму квадратов чисел от 1 до 10 000 000, распределяя работу между
потоками выполнения Julia, и проверяет результат по формуле суммы квадратов.

## Язык и запуск

- Язык: Julia 1.11.5
- Файл: `main.jl`
- Обычный запуск - четыре потока:

```
julia --threads=4 main.jl
```

- Можно задать другое число потоков, программа подстроится и разобьёт диапазон
  на столько же частей:

```
julia --threads=7 main.jl
```

Порядок строк с частями и номера потоков от запуска к запуску меняются - это зависит от

всегда одинаковые, меняется только время работы.

## Разбор решения

1. **Тип `Int128`.** Сумма квадратов до 10 000 000 - это примерно `3.3 * 10^20`, в `Int64`
   не влезет. Поэтому накопитель и массив результатов имеют тип `Int128`.
2. **Сколько частей.** Программа спрашивает у Julia `Threads.nthreads()` и делит диапазон
   ровно на столько же частей.
3. **Остаток от деления.** Размер части считается нацело: `div(10 000 000, 7) = 1 428 571`,
   и семь таких частей не покрывают последние три числа. Поэтому последняя часть
   заканчивается не `part * part_size`, а самим `MAX_NUMBER`.
4. **Замер времени.** `@elapsed` вокруг блока с потоками даёт время параллельного счёта.
5. **Проверка.** Итог сверяется с формулой `n(n + 1)(2n + 1) / 6`, посчитанной в `Int128`.
   Это независимый способ убедиться, что сумма верна.
